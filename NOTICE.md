# Attribution

Derived from Russell K. W. Spencer's [SCFT_string](https://github.com/PolymerTheory/SCFT_string)
code accompanying Spencer et al., *Membrane fission via transmembrane contact*,
Nature Communications 15, 2793 (2024), https://doi.org/10.1038/s41467-024-47122-w.
MIT attribution is preserved. Protein and arc geometry are subsequent extensions.

The protein-capable lineage was used in Russell K. W. Spencer and Marcus Müller,
*Dynamin optimizes protein-membrane interactions for fission*, npj Soft Matter 2,
6 (2026), https://doi.org/10.1038/s44431-026-00018-9.
The current cleaned arc implementation is derived from that research lineage;
this citation does not identify the current commit as the historical calculation version.
